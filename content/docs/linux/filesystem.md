## What is the Linux filesystem?

Linux uses a hierarchical directory structure.

| Directory | Purpose |
|----------|---------|
| /        | Root |
| /bin     | Essential commands |
| /etc     | Config files |
| /home    | User data |
| /var     | Logs & variable data |

### Useful commands

```bash
ls -l
df -h
du -sh *
```
